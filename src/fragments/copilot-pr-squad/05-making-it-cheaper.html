How I measured it

Cost here is Copilot usage in AI credits, read from the session history on the machine that runs the squad. The Copilot CLI records every model call there with its tokens and the AI credits they cost, and the squad adds those up for each run, including the agents it starts. A run’s total rises with how many PRs it works, so the fair comparison holds the work steady: cost per run when runs did about the same amount of work, and cost per PR on busy runs.

About these numbers

I only started logging cost per run on Oct 6, and per PR that evening, so the per-run figures here were rebuilt afterwards from session history: 69 runs that started agents, from Sep 29 to Oct 8. Runs that stopped because nothing changed aren’t in it. The three Oct 7 changes landed about seven hours apart, so their effects can’t be separated.

The result

Runs after the changes started about as many agents as runs before them, and cost about a third less. On busy runs, the cost per PR roughly halved. The Coordinator saw the biggest drop.

Trying a cheaper model

The Reviewer and Communicator were the biggest cost, so before switching either I compared two models, the one they ran on and one known to be cheaper. I replayed real past rounds on both, in a sandbox that couldn’t post.

The cheaper model’s comments were vaguer, and in two ways they would have sent Copilot the wrong way: a point that didn’t apply, and tests nobody needed. Each of those costs another hourly round, which is worth more than the saving. I kept the current model.

That doesn’t mean every agent needs the biggest model. The Tester, Scribe and Fact Checker run on a smaller, cheaper one, Sonnet, by default, because their work follows set steps: run the existing checks, update the records, check a comment’s facts against GitHub. The Communicator’s charter allows it too for simple rounds, like moving a finished draft to ready.

The lessons I took:

  • Measure cost per unit of work from day one. I didn’t, and had to rebuild the first week’s baseline afterwards.
  • Experiment before changing a model. A lower cost always gives something up, and here it would have been extra rounds. But the most expensive model isn’t needed everywhere, and only a test on real work shows where it is.
