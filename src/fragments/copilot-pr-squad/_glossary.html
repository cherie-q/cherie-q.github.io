Terms used in this series
TermMeaning
Copilot coding agentGitHub Copilot working on an issue assigned to it: it opens a draft PR and pushes commits, one session per @copilot comment.
bradygaster/squadThe open-source framework the squad is built on: a team of agents with written charters, run by a coordinator.
Run (tick)One hourly pass of the squad over every PR. The squad’s own files call it a tick.
RoundOne cycle on one PR: review, checks, one comment to Copilot, then wait for its next push.
Watch-only (shadow mode)The squad does everything except write to GitHub, and records what it would have posted.
Review briefA short file I write for one issue that pins what its PR may touch.
Known breakA failure on main, or a flaky test, that is tracked by an issue, so the squad doesn’t send it to Copilot.
AutomationA saved agent task that the GitHub Copilot app runs on a schedule. The squad’s hourly run is one.
